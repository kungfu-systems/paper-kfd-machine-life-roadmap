# Contributing

This repository is published by Kungfu Origin Technology Limited and follows
the Kungfu public repository baseline.

## Changes

- Keep paper source in `paper/`.
- Keep repository and process notes in `docs/`.
- Do not commit generated PDFs or LaTeX build artifacts.
- Cite primary sources where possible.
- Label observed facts, engineering inferences, and untested hypotheses.
- Do not turn functional machine-life language into claims of consciousness.

## Commit Requirements

Commits require Developer Certificate of Origin sign-off, lightweight
Conventional Commits, and English commit and pull request text.

## Checks

Run `make check`. If a TeX toolchain is available, also run
`make pdf`.
